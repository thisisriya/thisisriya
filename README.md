## About

I build things that turn raw signal into an answer someone can act on.

Right now that means **SuryaShield**, a platform that reads Aditya-L1 X-ray data and forecasts solar flares before they arrive — and before that, a lost &amp; found portal that understood *"black wallet, brown stitching"* well enough to find its owner. Two very different problems, one shared idea: the model is only half the work. The other half is the interface that makes people trust it.

I'm an undergraduate in **Artificial Intelligence and Data Science** at PIET, Samalkha. Between semesters I've analysed datasets as a Data Analyst Intern in New Delhi, shipped Unity applications as a software trainee, and spent an unreasonable amount of time discovering that the gap between a mediocre LLM output and a great one is usually the prompt.

## Featured Work

### <img src="https://img.shields.io/badge/01-8B5CF6?style=flat-square&labelColor=8B5CF6" /> &nbsp;SuryaShield · *Solar Flare Prediction Platform*

<sub>`May 2025 – Present`</sub>

A solar flare doesn't announce itself. SuryaShield reads soft and hard X-ray data from **Aditya-L1** and forecasts what's coming — nowcasting for the minutes ahead, forecasting for the hours after — then renders the whole picture on a responsive dashboard built for people watching in real time, not for people reading a paper.

> **The number that matters** — ML models reaching **87% accuracy on validation data**.

Real-time monitoring · probabilistic forecasting · risk visualization

### <img src="https://img.shields.io/badge/02-A78BFA?style=flat-square&labelColor=A78BFA" /> &nbsp;FindIt.AI · *Lost &amp; Found Portal*

<sub>`Jan 2025 – Mar 2025`</sub>

Keyword search fails at lost &amp; found, because nobody describes the same object the same way twice. FindIt.AI uses the **Google Gemini API** to match descriptions by meaning rather than by string — so "navy backpack, side pocket torn" finds the listing that says "dark rucksack with a damaged pocket," and tells the person who's been looking for it.

> **The number that matters** — roughly **80% similarity-based notification accuracy**.

Intelligent description matching · full-stack integration · owner notifications
